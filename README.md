# 百度网盘 · 群组共享文件清单导出器

> 遍历百度网盘「通讯录 → 群组 → 群文件」里的共享目录，把所选目录的**全部文件明细**导出为
> **CSV（Excel 可直接打开）/ JSON / 目录树 TXT**，内置**完整性自检**与**任务台账**。
> 支持**边扫边写·流式自动存盘**（超大目录也不卡死）、**断点续抓**（关页面/刷新后续跑）。
> 与 LinkSwift 等下载类脚本**并存互不干扰**。

## 它能做什么

- **一键导出群共享文件清单**：自动递归遍历你加入的群组共享目录，输出每个文件的
  名称、大小、路径、分类、修改时间等字段。
- **三种导出格式**：
  - `CSV` —— 用 Excel / WPS / Numbers 直接打开，做筛选、统计、查重；
  - `JSON` —— 供程序二次处理；
  - `目录树 TXT` —— 一眼看清目录层级结构。
- **边扫边写·流式存盘**：扫描过程中每隔几秒把结果**追加写入同一个 CSV 文件**并清空内存，
  无论总量多大都不会把浏览器拖垮，扫完自动保存关闭，整晚挂着不用管。
- **断点续抓**：进度压缩后存入 IndexedDB。关页面、刷新、或手动停止后，面板顶部出现
  「继续上次扫描」，从剩余目录接着跑，**不会重扫已完成的部分**。
- **有界并发 + 自动降速**：默认 3~5 倍速扫描，触发百度限流（风控）时自动降回单路并拉长间隔，
  不硬扛风控。
- **完整性自检（离线、秒出）**：核对是否被中断、队列残留、请求报错、重复 fs_id、
  是否触顶翻页/深度、未展开目录数。全过则没有漏抓理由，无需重扫。
- **任务台账 / 扫描记录 / 核对报告**：每次扫描自动留档，可事后导出 CSV 核对。
- **内存护栏**：单次扫描达 25 万条明细自动暂停，避免撑爆内存。
- **可拖动状态浮窗**（v1.3.8 修复拖动失效）。

## 适用人群

- 想给某个群共享资料**做完整归档 / 备份清单**的人；
- 需要**按文件名、大小、时间筛选**群文件的人；
- 想**核对「群文件有没有被删/漏」**的管理员；
- 做**资源整理、去重、迁移**的人。

> ⚠️ 本工具**只导出文件清单（元数据）**，**不提供文件下载**。
> 百度对群分享里的大文件不签发下载直链（dlink）；要下载请在群里点「保存到我的网盘」，
> 再用百度客户端或下载助手处理。

## 支持的浏览器

| 浏览器 | 边扫边写（自动存盘） | 说明 |
| --- | --- | --- |
| **Edge / Chrome** | ✅ 完全支持 | 依赖 File System Access API，需你**本人点一次**选保存位置 |
| **其它 Chromium 内核** | ✅ 基本支持 | 同 Edge/Chrome |
| **Firefox** | ⚠️ 回退为内存模式 | Firefox 不支持 File System Access API，流式自动存盘会回退：结果存内存，扫完手动「导出 CSV」即可 |

推荐 **Edge / Chrome**。脚本管理器推荐 **Tampermonkey** 或 **Violentmonkey**。

## 使用步骤（3 分钟上手）

> **前置条件**：已登录百度网盘网页版，并且**先在左侧点开一次「通讯录 → 群组 → 群文件」**。
> 这一步是为了让脚本嗅探到页面请求里的 `bdstoken` 等参数——只要点开过一次，之后全自动适配，
> 百度改参数名也不怕。

1. 打开并登录 <https://pan.baidu.com>，进入任一群组共享文件页。
2. 页面右下角会出现一个 **「清单 / 群文件」浮标**，点它打开面板。
3. **① 选择群组**：点「刷新群组」拿到你加入的全部群（也可「从左侧读取」兜底），勾选要导出的群。
4. **③ 读取目录结构**：点「① 读取目录结构」，脚本列出该群的共享目录，勾选你想导出的目录
   （一个都不勾 = 只导顶层直接分享的文件）。
5. **④ 开始扫描（边扫边写）**：点蓝色大按钮「② 开始扫描（边扫边写·自动存盘）」。
   - 浏览器会让你**选一次 CSV 保存位置**（这是浏览器硬性要求，之后全自动）；
   - 保持百度网盘标签页在前台（不要最小化），剩下的交给脚本。
6. 扫完后，在 **⑤ 导出文件明细** 里可再导出 CSV / JSON / 目录树，或点「完整性自检」核对有无漏抓。

> 浮窗可**拖动**到不挡视线的位置；位置会被记住，下次打开自动恢复。

## 核心功能详解

### ① 群组选择

- **刷新群组（走接口）**：最可靠的来源，返回你加入的全部群组（含 gid / 名称）。
- **从左侧读取（兜底）**：新版百度侧栏的群入口链接不再带 gid，抓不到时会自动回退到接口，
  请优先用「刷新群组」。
- 支持**搜索群名**、**手动添加群 gid**、**全选/清空/只选当前群**。
- 未勾选任何群时，默认导出「当前正在浏览的群」。

### ② 扫描设置

| 参数 | 含义 | 备注 |
| --- | --- | --- |
| 扫描速度 | 一键切换并发与间隔 | 保守 / 标准(3~5×) / 极速(6~8×，可能触发风控) |
| 请求间隔 | 每次请求前等待 | 防风控，不建议调到 0 |
| 每 N 次休息 | 连续请求 N 次后长休息 | 避免高频被限流 |
| 单页条数 | 单目录一次抓多少条 | 百度**硬上限 100**，默认 100 最优 |
| 单请求超时 | 单次请求最长等待 | 浏览器 fetch 默认永不超时，必设 |
| 最大深度 / 最大翻页 | 递归层数 / 单目录翻页上限 | 触顶会标注「可能不完整」 |
| 读取结构最大页数 | 「读取目录结构」翻几页群消息 | 群消息多时请调大，否则漏目录 |
| 导出包含文件夹行 | CSV/JSON 是否列文件夹本身 | 关闭则只输出文件 |

并发只作用于**不同目录之间**；单个目录的翻页仍严格串行。触发限流
（`errno 4 / 9013 / 31034 / 9019` 等）会自动降回单路。

### ③ 选择导出目录

- 勾选目录后，导出明细**只包含这些目录内部**的文件与子目录，**不含根目录下的同级条目**。
- 一个都不勾 → 只导出顶层直接分享的文件。
- 「读取目录结构」只刷新本清单，**不会清空**下方已有结果。

### ④ 执行与进度（边扫边写）

- 点「② 开始扫描（边扫边写）」后脚本自动：读结构 → 沿用你勾选的目录（没勾则自动全选）
  → 让你选 CSV 保存位置 → 开始扫描。
- 扫描时每几秒把结果**追加写入同一个 CSV** 并清空内存；可暂停/继续/停止/清空。
- 进度条、实时统计（已写行数、队列剩余、已展开目录、请求数、错误数）实时显示。
- **边扫边写要求 Chrome/Edge**；Firefox 下自动回退为内存模式（扫完手动导出 CSV）。

### ⑤ 导出与自检

- **CSV (Excel)** / **JSON** / **目录树 TXT** / **复制 CSV**（到剪贴板）。
- **完整性自检**：不发任何请求，秒级核对中断、队列残留、请求错误、重复 fs_id、
  是否触顶翻页/深度、未展开目录数。全过则无需重扫。
- 字段说明：**完整路径** = 相对本次共享目录的逻辑路径；**原始路径** = 分享者网盘里的原始完整路径
  （已自动 URL 解码为中文，如 `/书籍/读秀4.0/数据库25-1/xxx.zip`）。
- 导出文件名格式：`群名称_文件夹名_时间_类型.扩展名`
  （如 `音乐022_单曲2_20261108_204900_明细.csv`）；多群/多目录会自动缩写。

### ⑥ 日志与台账

- 面板日志实时滚动，可清空/复制/导出。
- **扫描记录（历史台账）**：每次扫描自动归档一条（目录级统计 + 完整事件日志 + 导出记录 +
  完整性结论），最多保留 20 条，可导出「核对报告 CSV」。
- **复制诊断信息**：排障时可一键复制环境信息发给作者。

## 已知限制与免责声明

1. **只导出清单，不下载文件**。百度群分享大文件不签发下载直链。
2. **Firefox 不支持流式自动存盘**（无 File System Access API），会回退内存模式。
3. **首次需点开一次群文件页**以嗅探请求参数；脚本只读观察、不修改你的任何数据。
4. 扫描频率受百度风控约束，极速档可能触发限流（会自动降速，但别把间隔硬调 0）。
5. **所有数据只存在你本地浏览器**（IndexedDB / localStorage），断点里**不含任何登录令牌**；
   请勿外发含 Cookie / bdstoken 的诊断信息。
6. 请遵守百度网盘服务条款，合理使用，勿用于批量爬取或骚扰他人。

## 常见问题 FAQ

**Q：面板里「开始扫描」点不动 / 浮窗拖不动？**
A：已在新版修复（v1.3.8）。若仍异常，请 F5 重载百度网盘标签页重新加载脚本。

**Q：为什么提示「未选择目标群 / 读不到目录」？**
A：先在左侧点开一次目标群的「群文件」让脚本识别当前群，或在「① 选择群组」勾选目标群，
   再点「① 读取目录结构」。刷新页面后勾选状态会重置。

**Q：为什么没有下载链接列？**
A：百度对群分享大文件不签发 dlink，本工具定位是「清单导出」而非下载。需要下载请先「保存到我的网盘」。

**Q：触发限流/风控了怎么办？**
A：脚本会自动降回单路并拉长间隔，通常稍等即恢复。不要人为把「请求间隔」调到 0。

**Q：关了页面/浏览器，扫描进度会丢吗？**
A：不会。断点存在 IndexedDB，重开后在面板顶部点「继续上次扫描」即可从剩余目录接着跑。

**Q：和 LinkSwift 等下载脚本冲突吗？**
A：不冲突，可并存。本工具只做清单导出。

**Q：中文在 Excel 里乱码？**
A：CSV 含 UTF-8 BOM，Excel 双击通常正常；若仍乱码，用「数据 → 从文本/CSV 导入」并选 UTF-8。
